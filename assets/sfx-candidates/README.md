## 关于「Block Blast 原音效」

- 原版音效版权归 **Hungry Studio / Block Blast!**，不能直接塞进我们工程商用。
- 网上有研究向拆包合集（**仅试听 / 对标音色，勿直接上架**）：  
  [The Sounds Resource — Block Blast! Sound Effects](https://sounds.spriters-resource.com/mobile/blockblastblockjuggle/asset/470047/)
- 下面这批是 **Freesound 免费近风格参考**（偏 casual 手游：软弹、泡泡、sparkle、短 jingle）。

原版大致气质（对标用）：

| 事件 | 听感 |
|------|------|
| 拿起 / 轻触 | 极短、偏塑料/软胶 UI click，不刺耳 |
| 多线消除 | 更亮：pop / swoosh + sparkle 或短胜利 chime，比单线更「炸」 |

## `clear_multi/` — 多线消除（清脆 + 破碎）

旧版 sparkle/jingle 已挪到 `clear_multi/_archive_soft_jingle/`。  
当前根目录是 **玻璃 / 瓷片 / 冰裂 / 脆 snap** 向：

### 优先试（更偏手游「脆碎」）

| 类型 | ID | 时长感 | 说明 |
|------|-----|--------|------|
| 极短玻璃脆响 | **368357** / **368339** | ~0.2s | 清脆击裂，不拖沓 |
| 短玻璃 hit | **368350** / **368337** / **368333** | 0.4–0.5s | 同系列变体 |
| 设计感 crack | **446118** | 0.6s | 游戏化碎裂 |
| 瓷砖/瓷片 | **583310** / **128286** / **128266** | 0.5–0.7s | 方块碎更贴 |
| 冰裂脆 | **18177** / **624163** / **177215** | 0.6–0.8s | 清脆裂开 |
| 脆 snap | **614740** / **614742** / **665085** | 0.4–0.7s | 干脆折断 |
| 完整碎裂 | **41348** / **233607** / **267889** | ~1s | 更「整片碎」 |
| 碎片余韵 | **778603** / **521348** | 0.8–1.2s | 渣子声 |

**建议听序：**  
1. `368357` `368339`（短脆）  
2. `446118` `583310`（游戏/瓷片）  
3. `18177` `614740`（冰裂/snap）  
4. 若要更「炸」再听 `41348` `233607`
