# 配色检索计划 v2

> **状态**：暂停合入默认色大改。检索进行中；反查见 `docs/color-research/GAP-AUDIT.md`。  
> **气质偏好**：**轻松愉快、不压抑**（深色只用于槽位等局部，不作整 UI 暗黑风）。  
> **目标**：块（L4）最清晰；格子 / 背景 / 预填为辅助。  
> **约束（产品共识）**：
>
> - 棋盘**预填**使用**一个主色系**（可有深浅）
> - **候选块**不能与盘面主色系（及接近色系）相同
> - 玩家落入盘面的块**保留候选原色**
>
> **代码映射**：`defaults.js` · `generator.js`（palette / `colorFamily` / ban）· `bg-tune` · `board-tune` · `tray-dock-tune` · `piece-tune`  
> **产出目录**：`docs/color-research/`（`refs/` · `catalog.csv` · `FINDINGS-v1.md` · `GAP-AUDIT.md`）

**版本**：v2（吸收反查补漏）· 替代 v1 过期待办

## 2. 检索问题（每 case）

**核心（P0）**

1. L4 在 **L3** 上是否一眼可见？  
2. L4 在 **L2 旁 / 压在预填语境**是否仍清楚？（无 L2 则填 N/A 并注明空盘）  
3. L3 与 L2 是否分得开？  
4. L0 是否压抑或过抢？（偏好：不压抑）  
5. tray 多块彼此是否好认？  
6. 是否满足「盘面一系 + tray 不同系」？无预填则 match=low  
7. 若有多关/多主题：换主色后是否崩？

**补漏（P1）**

8. **L5** 投影在该盘面上是否够看、会否脏？  
9. **L6** dock 是浅/深/无，是否抢 L4？  
10. **L7** 字在壳上是否够看？

## 6. 成功标准（修订）

1. L4 在 **L3** 上主观 ≥ 4/5（**所有**测试主色系）  
2. L4 在 **L2 语境**主观 ≥ 4/5（无则方案不适用我们）  
3. L3 与 L2 不糊  
4. L0 **不压抑**（oppressive ≤ 2）且 **愉快**（cheerful ≥ 4）— 与偏好绑定  
5. 跨 ≥3 预填主色系方差可接受  
6. 预填单系 + tray ban + 落子原色 **完整保留**  
7. catalog 中 **E≥3** 且 **B 轻松深槽≥4** 后，才进入阶段 4 选型
