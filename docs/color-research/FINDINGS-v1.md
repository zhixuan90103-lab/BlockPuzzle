## 2. 偏好过滤：轻松愉快 × 清晰

对 catalog 主观分（1–5）：

| 指标 | 含义 | 偏好权重 |
|------|------|----------|
| cheerful | 轻松愉快 | **高** |
| clarity_L4 | 块清晰 | **最高** |
| oppressive | 压抑（越高越差） | **高（要低分）** |

### 落点观察

| 类型 | cheerful | clarity | oppressive | 结论 |
|------|----------|---------|------------|------|
| **纯深井 A**（工业/近黑盘） | 2–3 | **5** | 3–4 | 清晰冠军，**气质偏沉**，与「不压抑」冲突 |
| **浅壳 + 深槽 B**（粉壳褐盘、periwinkle 壳） | **4–5** | **5** | **1–2** | **同时满足愉快与清晰** |
| **浅壳 + 浅洞 C**（我们 sky / cream mock） | **5** | 2–3 | **1** | 愉快但**块不够跳** |
| **中紫壳 + 蓝预填**（我们当前截图） | 3 | 3 | 3 | 壳尚可；**预填与洞同冷色**拖清晰 |

**偏好下的优选区间**：

> **L0 中～高明度、中～中高饱和的「开心壳」**  
> **L3 明显更暗的槽（不必纯黑）**  
> **L4 中高饱和、色相拉开的「玩具块」**  
> **L2 预填：同色系但闷、略暗，绝不当第二套糖果**

## 3. 可复用公式（阶段 2 初稿）

在「轻松愉快」过滤后，成立的规律：

### F1 · 壳可以亮，槽必须暗一截
- 参考：粉壳 / 浅紫壳 + 深褐/深蓝井 → 不压抑且块清楚。  
- 失败：壳亮 + 洞也亮 → 愉快但糊（我们 sky 时期）。

### F2 · 块的「跳」主要靠相对 L3/L2，不是绝对荧光
- 深槽上中高饱和粉蓝绿就够；浅洞上再艳也容易漂。

### F3 · 预填是我们的特殊项
- 竞品 A/B 多是「空盘 + 玩家彩块」。  
- 我们有大面积 L2：必须 **L2 明度/饱和夹在 L3 与 L4 之间**，且与 L4 **色系隔离**（已有 ban）。

### F4 · 同色系深浅预填时，洞尽量「去色」
- 洞若也带蓝相，会和蓝预填糊（当前紫壳蓝预填截图问题）。  
- 洞用**中性深灰/深褐灰**比「深蓝空」更稳。

### F5 · 3～5 个高辨识 tray 色优于 10 个近色
- 参考彩虹盘靠深槽；tray 三块时色相间隔要大（粉/紫/黄或粉/蓝/绿）。

### F6 · 不压抑的壳色候选（检索归纳）
- 天蓝、粉底、浅紫、奶油、雾薄荷 — **中高 L**  
- 避开：大面积近黑壳、低 L 灰紫铺满

## 4. 与产品共识的合成（检索结论）

| 共识 | 在「轻松愉快」下的写法 |
|------|------------------------|
| 预填单色系 | 保留；做成**闷地形**（中低 S、中 L） |
| tray 不同系 | 保留 ban；tray 用**开心糖果/软糖**中高 S |
| 块最清晰 | **L3 深中性槽 + L4 高辨识**；不靠压黑整个 UI |
| 不压抑 | **L0 保持亮/中亮**；深色只给槽和盘托局部 |

## 5. 暂缓方案方向（仅命名，阶段 3 待小样）

以下**只作检索结论候选**，本阶段不改默认色：

### 方案 P1 ·「开心浅壳 + 中深中性槽」（最贴偏好）
- L0：天蓝 / 粉底 / 浅紫（可选主题）  
- L3：**中深中性**（深灰蓝或深灰褐，**低彩**）  
- L2：闷单色系  
- L4：中高饱和 4～6 色，ban 主系  
- 气质：休闲愉快；清晰靠槽块差

### 方案 P2 ·「浅壳 + 偏深井」（偏参考 B/A 清晰）
- L0 仍亮；L3 更深（仍非纯黑）  
- 清晰更高；愉快略低于 P1

### 方案 P3 ·「奶油台 + 跳色块」（纯 C 加强）
- L0/L1 很亮；L3 仅中灰  
- 愉快最高；清晰依赖 L4 与 L3 的 S/L 差，**风险最大**

**检索推荐优先验证：P1**（符合「轻松愉快」且有清晰路径）。

## 6. 外部知识摘要（轻松休闲向）

- **Pastel UI**：高明度、偏低饱和 → 轻松，但图形对比常不足；需 **明度阶梯或描边** 补（Figma / 行业 pastel 指南）。  
- **Hyper-casual**：品牌色鲜艳 + 可点目标高对比（CrazyLabs 类指南）→ tray/块可更「按钮感」。  
- **开心消消乐等国区休闲**：文案强调「清新明丽」→ 与「不压抑」同向，非暗黑竞技风。

## 8. 一句话结论

> 在「轻松愉快、不压抑」前提下：  
> **不要用整 UI 压黑换清晰**；  
> **用「亮壳 + 明显更暗的中性槽 + 高辨识操作块 + 闷预填」**。  
> 深井糖果（A）清晰但偏沉；粉壳褐盘（B）与开心浅壳中深槽（P1）更符合当前偏好。
