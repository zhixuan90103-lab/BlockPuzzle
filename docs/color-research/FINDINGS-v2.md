## 4. 关键风险（补漏后仍在）

1. **外部 E 金样不足** → 预填明度夹逼仍偏理论。  
2. **hex 多为目测/约值** → 阶段 4 须吸色校准。  
3. **L5 ghost** 多数 N/A → 浅盘/深盘投影策略未收敛。  
4. **双人评分未做** → 主观分单源。  
5. **工程默认色** 与「检索冻结」可能并存试色痕迹 → 选型以本文公式为准。
