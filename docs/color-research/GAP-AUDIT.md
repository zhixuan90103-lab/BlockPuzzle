## 3. 样本结构偏差（反查统计）

| 观察 | 数字 | 风险 |
|------|------|------|
| match_our_rules=high | 仅 ours 3 条 | 外部几乎都不含「大面积单系预填」 |
| match_our_rules=low | 多数 A/B | 学清晰可以，**不能直接抄空盘逻辑** |
| cheerful≥4 且 clarity≥4 | 很少（主要 B-gingham、部分 peri） | **轻松∩清晰**样本不足，需优先补 B |
| 含稳定 L2 预填描述 | 弱 | 高估「空盘公式」可迁移性 |

## 4. 结论：计划必须改什么

1. **把桶 E + L4-on-L2 + 跨色系** 升为阶段 2 完成条件（非可选项）。  
2. **强制分层字段** L5/L6/L7，避免只评「整图好看」。  
3. **轻松愉快** 写进成功标准与过滤，深井 A 仅作清晰上限对照，不作默认目标。  
4. **冻结默认色** 直到阶段 4 评分完成。  
5. catalog **扩列**，补 hex 与 L4_on_L2。  
6. 阶段 3 方案必须含 **P1（开心浅壳+中深中性槽）** 且给草案 hex。
